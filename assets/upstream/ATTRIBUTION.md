# Project icon sources

These original upstream icons identify projects contributed to; they are not original artwork by 1clipse. Colors and proportions are preserved. Source commit IDs and blob hashes are recorded in `sources.json`.

- **CC Switch** — [farion1231/cc-switch](https://github.com/farion1231/cc-switch), `src-tauri/icons/128x128@2x.png`.
- **Hive** — [tt-a1i/hive](https://github.com/tt-a1i/hive), `assets/logo.png`, also used in the upstream README.
- **CCB** — [SeemSeam/claude_codex_bridge](https://github.com/SeemSeam/claude_codex_bridge), `mobile/app/assets/brand/ccb-mobile-icon-1024.png`, the project's official mobile application icon.

The SVG card headers embed these files unchanged in a surrounding layout. Project names, icons, and trademarks belong to their respective owners. This profile describes contributions, not project ownership or endorsement.
